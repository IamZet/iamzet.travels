# iamzet.travels

Путешествия Александра Захарова с 2001 года: путевые заметки, фотографии, видео и карты маршрутов.

Сайт: https://iamzet.ru

Статический сайт без сборки на сервере, публикуется через GitHub Pages.

- `index.html` — список всех поездок
- `trips/` — страницы поездок (вкладки Заметки / Фото / Видео / Карта)
- `photos/` — фотографии из альбомов (без метаданных и геометок)
- `covers/` — обложки поездок
- `assets/` — стили, скрипты, флаги

Видео проигрываются с Дзена / YouTube, старые ролики — из Yandex Object Storage.
